Task composition is also a concern: 1,442 of 1,442 tasks (100.0%) contain both labels, so task identity can be informative while still allowing within-task cross-class comparisons. Language is a direct potential proxy where its class counts above are uneven. Generator and source are potential provenance proxies whenever their values are concentrated in one class; they must not be used as model features.

## 7. Task-Disjoint Evaluation Feasibility

A deterministic seeded task-level search (`seed=42`) selected whole tasks for an approximately 20% test set while minimizing deviation from both the overall test-row target and per-class test-row targets. It uses all tasks across train and test and never splits a task.

| split | rows | tasks | Ai_generated rows | Human_written rows |
|---|---|---|---|---|
| train | 9456 | 1154 | 4914 | 4542 |
| test | 2371 | 288 | 1229 | 1142 |

- **Task overlap between train and test:** 0
- **Test fraction by rows:** 20.047%
- **Class proportions in train:** Ai_generated=51.967%, Human_written=48.033%
- **Class proportions in test:** Ai_generated=51.835%, Human_written=48.165%

This demonstrates feasibility for this artifact. The recommended evaluation is this task-grouped split with `seed=42`, retaining all suitable tasks after exact normalized-code deduplication policy is decided. Report the held-out task list or a stable split manifest so the evaluation can be reproduced. Because tasks can contain both classes and task sizes are unequal, exact row-level 80/20 and exact class balance are not guaranteed by a group-disjoint split.

## Critical Limitations

- Task name is the available grouping identifier; it may not capture duplicate prompts, source provenance, student identity, or generator prompt families.
- Exact duplicate detection catches identical normalized code, not semantic or near duplicates.
- The report is descriptive only. It does not establish that language, source, generator, or task effects are causal.
- Install the only non-standard dependency with `.\.venv\Scripts\python.exe -m pip install pyarrow` if `pyarrow` is unavailable.
